# WI-018 handoff — UAT bigger items

Branch `feat/wi-018-uat-bigger` from `main` (after PR #23). Scope: the three "bigger" items (17–19) from the production acceptance pass of 2026-10-22. No schema change, no migration, no new dependency.

## 1. Outcome

17. **Settings with a left index.** The page is five groups, Reminders · Calendar · Appearance · Account · Data, each a `#id` anchor, with a sticky index on the left (`src/features/settings/index-nav.tsx`, client) that marks the group in view through an IntersectionObserver. Under 1100 px the index is a sticky row of pills above the groups. The Notifications card is titled Reminders; the Getting started checklist keeps its anchors; System status and the export sit under Data.
18. **Routine editor as a short form.** `RoutineForm` shows Title, Repeat on and the start and end times; category, goal, priority, notes, Active and the overlap switch sit behind "More: category, goal, priority, notes" (`src/components/form-more.tsx`, which hides with the `hidden` attribute so the fields stay mounted, their defaults still submit and a kept draft still lands). Editing a routine shows "Apply changes to" in the open part and opens More by itself when the routine uses any of its fields. The first-run card on Today uses the same form.
19. **Drafts for in-place forms.** `src/components/drafts.ts` keeps what is typed in the browser tab's `sessionStorage` under a key the page chooses. `ActionForm` takes `draft="<key>"`: it writes the fields on every change (only while something differs from what the page rendered), applies a kept draft once after hydration, shows "Draft kept on this device. Discard", and clears the draft on a successful save or on Discard. `Disclosure` takes the same `draft` key and opens itself while a draft exists, so Back, a refresh or a closed panel never loses the text. Hidden fields, tokens, request ids and versions are never stored; nothing leaves the device. Keyed forms: add block (`block:<day>`), add routine (`routine:new`), add application (`application:new`), add interview (`round:<application>`), job timeline note (`job-note:<application>`), daily review (`daily-review:<day>`), weekly reflection (`reflection:<week>`), weekly priority (`priority:<week>`), new goal (`goal:new`), new roadmap (`roadmap:new`), add items (`items:<roadmap>`).
