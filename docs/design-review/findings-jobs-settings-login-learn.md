# Code-review findings (read-only agent pass)

Source: a read-only code review by a delegated agent on 2026-10-21. Evidence is file:line; nothing here was run in a browser.

All paths below are under /Users/shamstabrez/Desktop/FullStack/CareerOs/. I read the code only. Nothing was run in a browser, so the visual findings come from reading the CSS.

Notes that apply to every screen:

- Spacing is mostly hard-coded. src/app/globals.css has 612 `px` values and only 2 uses of `var(--space-*)`, even though the tokens exist (src/app/design-tokens.css:39-47).
- Several radii fall outside the token scale: `.button` 10px (globals.css:183), `.pill` 6px (globals.css:163).
- Some selectors are defined twice: `.dsa-item` (globals.css:519 and :1755), `.prep-item` (580 and 644), `.login-card` (659 and 803).
- No `h4` rule exists. Tailwind's base reset therefore makes every `<h4>` look like body text.
- No page sets its own title except login (only src/app/layout.tsx:16 and src/app/login/page.tsx:12 have metadata), so every browser tab reads "Silsila".
