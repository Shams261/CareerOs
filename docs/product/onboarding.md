# Owner onboarding checklist

For the owner's first days on a deployed Silsila. The app leads with the first step itself: Today shows a single **Start here** card until the first routine exists, and Practice, Learn and Jobs do the same for their first topic, subject and application. Settings → **Getting started** lists the remaining steps and disappears when they are done.

## First sign-in (10 minutes)

- [ ] Open `https://<host>` and **Sign in with Google** with the account in `OWNER_EMAIL`.
- [ ] Settings → Account: the email and timezone are right. The timezone (default `America/Toronto`) decides every local date and reminder time.
- [ ] Settings → System status: Database _Healthy_, Session time zone _UTC_, Schema _Current_.

## Make the week yours

- [ ] Today → **Start here**: add the first routine block (what, which days, what time). Today and the rest of the week fill in from it. More routines: Plan → **Add routine**. Editing a routine changes days not planned yet unless you choose to apply it to planned days (previewed first).
- [ ] Practice: add the current topic and a few problems.
- [ ] Learn: add the subject you are focusing on.
- [ ] Jobs: add the applications already in flight, with next actions and dates.

## Reminders on your devices

- [ ] Settings → Notifications → **Daily progress reminder**: pick the evening time.
- [ ] On each device you want alerts on, open Settings → **Enable notifications**, allow the prompt, then **Send test notification** and confirm it arrives.
- [ ] iPhone/iPad: first Share → **Add to Home Screen**, open Silsila from the icon, then enable notifications there.
- [ ] Close the app/browser tab and wait for the next real reminder (for example the daily progress time) to confirm closed-app delivery on that device. Record which devices work.

## Google Calendar (optional)

- [ ] Settings → **Google Calendar** → **Connect Google Calendar**, approve the limited permission, check that a **Silsila** calendar appears on your phone.
- [ ] Settings → Google Calendar → Categories to sync: untick anything you don't want in Google.

## Plan the next week

- [ ] Weekly review → step 3 **Next week** → **Prepare next week** (Sunday or Monday). With Google Calendar connected, next week appears there shortly after.
- [ ] Start using **Today**: Start / Complete blocks, record attempts and activities, finish the daily check-in.

## Safety habits

- [ ] Settings → **Download data export** once, to see what it contains (no credentials).
- [ ] Confirm the operator's backup schedule ran and a restore was verified ([backup and restore](../engineering/backup-restore.md)).
- [ ] Sign out on shared computers. Sign-in lasts 30 days per browser.
