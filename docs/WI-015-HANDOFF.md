# WI-015 handoff — design review rows 11–15

Branch `feat/wi-015-design-review-rows-11-15` from `main` (after PR #20). Scope: the last five rows of `docs/design-review/ENHANCEMENTS.md` section F. No schema change, no migration, no new dependency. With this WI every row of the review is implemented.

## 1. Outcome by row

11. **Copy and formats.** `shortDate(day)` ("Oct 28") and `weekdayDate(day)` ("Thu, Oct 22") in `src/lib/time.ts` take DATE labels and never touch a zone; they replace the ISO strings on Plan day headers, the problem page's next revision, the application page (due, applied, on-schedule, timeline), Jobs rows and Learn rows. The eyebrows lost the timezone id. Every page exports `metadata.title` ("Plan · Silsila"); dynamic routes use their section name. Block categories, the running panel's fallback and the calendar sync categories render through `categoryGroup`; resource types read as words. Nine explanatory paragraphs are gone or folded into labels (prompt template and scenarios, bulk items, follow-up done, sync categories, disconnect, conflicts, interview mentions, Learn suggestions); the follow-up form got an `h4` heading. "N of 3 green in a row" became "revision stage N" and the per-day pace is gone.
12. **Accessibility.** `ActionForm` refocuses the pressed button when the disabled fieldset dropped focus to the body. Execution controls, roadmap quick actions, prep toggles and note buttons no longer create form landmarks; their buttons carry the item name (sr-only or `aria-label`). The sidebar `<aside>` is "Workspace". `ShortcutsToggle` (Settings → Appearance) stores `silsila-shortcuts=off` per browser; `PageShortcuts` then ignores single keys and arrows (`?` and Escape still work), and the overlay is `aria-modal`, takes focus and has a Close button. Chain rings are 16 px with a 24 px link that reads "Thu Oct 22 · worked and reviewed". Every unicode glyph became a lucide icon with `aria-hidden` (arrows, checks, circles, chevrons, the subtopic corner) or a word ("Red to Yellow", "Applied to Technical"). axe-core is clean on Today, Practice, the roadmap page, the application page, the review and Settings.
13. **Buttons and tokens.** All 63 raw `<button className="button…">` are the shared `Button` (`cn('button', className)`; it renders `aria-busy` only while pending). `.button`, `.pill`, `.card` and `.hero` use `--radius-*` and `--space-*`; disabled buttons show `not-allowed`, busy ones `wait`. Merged: `.dsa-item`, `.prep-item`, `.login-shell`/`.login-card`, `.study-prompt`, `.item-filters` (one definition each). Removed: `.roadmap-mark`, `.roadmap-links`, `.roadmap-estimate`, `.pill.priority`, `.study-panel`, `.roadmap-sections`, `.pager`, `.login-card > .muted:last-child`. Breakpoints are 1100 and 700 only (the main grid and the Practice bands moved from 1050 and 900). New: a global `h4` and a rule that keeps inline icons on the text line (Tailwind's base makes `svg` block-level).
14. **Transitions.** `src/components/pending-region.tsx`: a client wrapper with `useTransition`; `usePendingRegion().start(work)` runs a navigation inside it. The region is `aria-busy` and `.is-pending` (content dimmed to 55%) until the URL changes, with an eight-second guard. Wired on the roadmap page (`.roadmap-layout`: section links, the phone select, the filters) and the Practice library (`#library`: search and status).
15. **Error and not-found.** `error.tsx` says "This page could not be loaded", shows the digest and offers Try again or Back to Today. New `not-found.tsx`. `loading.tsx` uses the skeleton lines. Login: sr-only "Sign in to Silsila." in the h1, `role="img"` on the logo, a note about Google's unverified-app notice; the owner-mismatch message names the checklist.

## 4. Notes

- `PendingRegion` relies on `useSearchParams`; the pages that mount it are dynamic, so no Suspense boundary is required.
- The shortcuts switch is per browser (localStorage), not a server preference; it meets WCAG 2.1.4 without a schema change.
- Converting raw buttons to `Button` is mechanical: inside `ActionForm` the fieldset still owns the disabled state and the pressed button its `aria-busy`.
